# Seuranta

Tutkan viikoittaisen tutkimusseurannan työtiedostot. Kansio ei näy sivustolla.

- `ehdotukset/VVVV-KK-PP.md` – viikkohaun ehdotuslistat (perjantaisin)
- `jono.md` – löydetyt mutta toistaiseksi valitsematta jääneet julkaisut
- `hylatyt.md` – käyttäjän hylkäämät ehdotukset

Hakuohje: `.claude/skills/tutkimusseuranta/SKILL.md`. Valitut julkaisut analysoidaan skillillä `tutkimusanalyysi`.
